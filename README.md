# CureVeya Surgical Care

A static React + Vite website for CureVeya Surgical Care, Bangalore.

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Before publishing

- Replace placeholder testimonials with approved real reviews.
- Add the official address, email address, clinician information, and privacy-policy URL.
- Ensure all service descriptions and medical claims are reviewed by qualified clinicians.
- Complete trademark and domain checks for the CureVeya name.
